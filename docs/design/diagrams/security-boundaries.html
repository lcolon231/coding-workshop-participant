Trust boundaries, admin path and supply-chain controls

CloudFront is the only way in: it signs every origin request and the IAM-protected Function URL accepts nothing else. It routes, it does not authorise, so every check still lives in the process. Admin commands arrive by synchronous Lambda invoke and must match exactly or the invocation is refused. Controls S1–S12 refer to docs/design/plan.md; the per-request chain is drawn in security-auth-chain.html.
